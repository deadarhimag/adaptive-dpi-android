# Применимость сетевых механизмов и транспортные альтернативы

Начальная матрица исследования 1B на дереве `3b30fdb6e1025ecaf72bdb89345d17369f33fc46`. У проекта minSdk 29, compileSdk 36 и NDK 28.2.13676358. Наличие API, разрешение в процессе приложения и эффект на проводе проверяются отдельно. Linux CI №98.1 использовал x86_64, loopback, ядро `7.0.0-1018-aws` и `sudo` для пакетного стенда. Эта серия не доказывает доступность в обычном Linux UID или Android. Предшествующие AVD-тесты API 34 проверяют конкретные продуктовые сценарии. Для опций с меткой «исторический AVD» использован отдельный запуск CI 45593797626, ядро 6.1 Android 14, APK debug. Это loopback-пробы, эффект на физическом маршруте отдельно открыт. По опциям с меткой «нет» отдельное проектное доказательство пока не найдено. «Физика» означает, какое утверждение о реальном устройстве требует отдельного согласованного опыта.

Для каждого рабочего варианта фиксируются полнота протоколов, мобильная воспроизводимость, устойчивость, управляемость жизненного цикла, практическая безопасность, throughput, latency и джиттер, CPU, память, потоки, FD, энергия, размер APK по ABI, время сопровождения и возможность безопасно отдавать сигналы будущему движку. Требуются повторяемые прогоны на одной нагрузке и сохранение проверок 1A. Здесь альтернативы квалифицированы по исходникам и интерфейсам. Сравнительных измерений и выбора архитектуры ещё нет.
