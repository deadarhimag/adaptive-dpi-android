# Дорожная карта

Номер этапа - это номер работы, а не версия приложения. Версию APK (`versionName`, `versionCode`) задаёт сборка, и она с этапами не связана.

**Цель первой рабочей версии:** пользователь включает приложение на Pixel 7 в сети Билайн - и YouTube в Chrome открывается сам, без настроек. Остальные возможности добавляются после того, как эта цель достигнута и проверена на телефоне.

Правило против бесконечного исследования: каждый этап заканчивается проверкой на Pixel 7; новый изолированный компонент не начинается, пока предыдущий не работает в реальном тракте.

## Этап 5. Пользовательский продукт

Always-on VPN и автозапуск (`SUPPORTS_ALWAYS_ON = true`, изменение манифеста по п. 27 AGENTS.md); интерфейс из [ARCHITECTURE.md](ARCHITECTURE.md); объяснения простыми словами; измерение батареи за сутки; матрица AVD API 29/34/36/37; подготовка релиза и уведомлений о лицензиях.

**Распространение - только GitHub Releases.** Release-сборка подписывается отдельным ключом выпуска; ключ хранится в секретах GitHub, не в репозитории. Workflow выпуска запускается вручную по тегу и прикладывает к релизу APK, SHA-256 файла и список изменений из коммитов. Приложение само в сеть за обновлениями не ходит: в «О приложении» - ссылка на страницу релизов и версия. Окончательная лицензия проекта выбирается до первого релиза (п. 14 AGENTS.md). Публикация релиза - только с разрешения пользователя (п. 15).

## Что удаляется из кода

Перед удалением проверить все места вызова, включая манифест, JNI, нативную часть, рефлексию и ресурсы (п. 25 AGENTS.md). Удаление выполняется отдельным коммитом с прохождением сборки и тестов.

**Формат сохранённых данных (п. 27 AGENTS.md).** Значения `CleanupStep.EngineMonitor`, `EngineTunnel`, `EngineStop` записываются в историю по имени и читаются через `CleanupStep.valueOf` (`VpnCleanupDetails`); `DiagnosticCode.EngineHung` хранится в журнале ошибок. Эти значения enum **не удалять**: либо оставить как устаревшие, либо добавить совместимое чтение старой истории с тестом.

## Порядок работы с ветками

- `main` меняется только после прохождения базового и расширенного Android CI.
- Работа этапов ведётся в `stage3-experimental` (или в ветках от неё); для Android CI открывается черновой pull request в `main` без слияния.
- `git push`, слияние в `main` и релизы - только с разрешения пользователя (п. 15 AGENTS.md).
